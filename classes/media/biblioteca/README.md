# Biblioteca de imágenes de las clases

Figuras elegidas de los manuales CTO 14.ª y AMIR (bucket R2 `eunacomvideos/Manuales_MIR/`).
Una carpeta por especialidad y dentro una por clase. Detalle con pie de figura: `indice.json`.
Lista por clase: `classes/docs/IMAGENES_ENCONTRADAS.md`. Lo que falta: `classes/docs/IMAGENES_FALTANTES.md`.
Archivos `S*_…__propio.svg`: figuras dibujadas por nosotros (curvas, gráficos y esquemas), sin derechos de terceros.
Se regeneran con `python classes/scripts/draw_figures.py` (código en `draw_figures.py` y `draw_schemes.py`).
